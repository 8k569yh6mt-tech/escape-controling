# escape-controling.xlsx

A Vampire Survivors-style game set inside an Excel sheet. You are the default Windows cursor, fighting off hordes of Excel formulas (`=SUM()`, `=IF()`, `=VLOOKUP()`, `=PY()`…) across five sheets full of fake financial reports.

**Play:** https://8k569yh6mt-tech.github.io/escape-controling/

- Move: arrow keys (or WASD / ZQSD)
- Aim: mouse, firing is automatic
- Pause: P or Esc

The whole game is a single `index.html` file with no dependencies. Progress is saved in your browser.
